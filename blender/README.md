# NIUA for Blender

Import AI-generated game assets into Blender — characters, meshes, rigs, motions, music — all generated on the web workbench at [niua.ohao.tech](https://niua.ohao.tech).

**Version:** 2.0.0 · **Blender:** 4.0+

---

## What this plugin does

**Import only.** Generation, chat, iteration, and preview all live on the web where they belong — blender is an assembly tool, not an iteration surface. The workflow:

1. **Generate on the web.** Chat with NIUA, preview, refine, pick the asset you want.
2. **Click "Send to Blender"** on the asset. A shareable link is copied to your clipboard.
3. **Paste into this plugin.** Press **Import**. The asset lands in your scene.

Links look like `https://niua.ohao.tech/import/job_<uuid>`. They're account-bound — pasting a link belonging to a different user returns "You don't own this asset." Screen sharing, chat history, and server logs don't leak your assets because the plugin authenticates with *your* API token separately.

## What gets imported

The plugin auto-detects the asset type from the link and uses the right Blender importer:

| Asset type     | Where it lands |
|----------------|---------------|
| Image          | Image Editor (split a window to see it) |
| 3D Mesh        | Scene outliner as a new GLB |
| Rigged mesh    | Scene outliner, armature + skin |
| Motion (BVH)   | Armature on the timeline, press Spacebar to play |
| Music (WAV)    | Saved to a temp file — drop into your DAW |

## Install

1. Build or download `niua-blender-2.0.0.zip` (`./build.sh` in this folder).
2. Blender: **Edit → Preferences → Add-ons → Install...**
3. Pick the zip. Enable **NIUA - Import AI Assets**.
4. Expand the add-on entry → paste your **API URL** and **API Token**.
5. Click **Test Connection**. Should show `✓ Connected — token valid · $X.XX`.

Panel lives at **View3D → Sidebar (N) → NIUA**.

## Get your API token

1. Sign in at [niua.ohao.tech](https://niua.ohao.tech).
2. **Settings → Developer → Generate Token.**
3. Copy, paste into Blender's NIUA preferences.

The plugin has a **Get API Token (Web)** button that opens that page directly.

> Every asset download deducts nothing extra — you've already paid for the generation. This plugin is just a transport.

## Use

### Normal flow
1. On the web: generate an asset, open the previewer, click **Send to Blender** (copies the link to your clipboard).
2. Alt-tab to Blender → NIUA panel → click **Paste**.
3. Click **Import**. Done.

### What the URL field accepts
Anything that contains a NIUA job UUID:
- Full URL: `https://niua.ohao.tech/import/job_abc-123-def`
- Bare UUID: `abc-123-def`
- With prefix: `job_abc-123-def`

Useful if you're copying from Slack, email, or browser URL bars — the parser finds the UUID.

## Troubleshooting

**✗ Token rejected (401)** — your API token is missing or revoked. Generate a fresh one.

**✗ You don't own this asset (403)** — the link was generated by a different NIUA account. Check you're logged into the same account that generated the asset.

**✗ Asset not found (404)** — either the link is stale, the asset was deleted, or generation hasn't finished yet. Wait ~30 seconds and retry.

**Nothing imports / Blender hangs** — the plugin downloads on a background thread and imports on the main thread. If Blender is doing other heavy work, the import can queue. Watch the status bar at the top of the panel.

## Architecture (for the curious)

One `__init__.py`, one HTTP client, one operator per top-level action. The import operator:

1. Parses the URL field for a job UUID (regex).
2. Calls `GET /api/download/job/{uuid}` with `x-api-key` header.
3. Server does ownership check + HEAD-checks R2 + returns presigned URL + pipeline type.
4. Plugin downloads on a daemon thread.
5. Routes to the right importer based on pipeline (`bpy.ops.import_scene.gltf` for mesh, `import_anim.bvh` for motion, `bpy.data.images.load` for image).
6. Status messages ride `bpy.app.timers` back to the main thread to touch `bpy.data` safely.

Adding a new asset type means: add a pipeline branch in `_import_by_pipeline()`. That's it — no new HTTP, no new operator, no new UI.
